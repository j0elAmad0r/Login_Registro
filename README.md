# Login_Registro - Diseño Móvil

## Descripción

Proyecto sencillo que muestra una pantalla de **Login y Registro** creada en **Android Studio con Kotlin y Jetpack Compose**.

Incluye campos de texto, botones y una imagen en la interfaz.

## Herramientas
* Kotlin
* Android Studio
* Jetpack Compose
